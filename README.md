# Jenishker & Keerthy — Engagement Invitation

A mobile-first, static engagement invitation website.

## Included
- Elegant cream/gold luxury design
- Hero photo
- Family names
- Engagement details
- Live countdown to 22 Nov 2026, 11:00 AM IST
- Google Maps directions
- Responsive photo gallery
- Share Invitation button
- No backend and no paid hosting required

## Free GitHub Pages hosting
1. Create a GitHub account if you don't have one.
2. Create a new repository, e.g. `jenishker-keerthy-engagement`.
3. Upload **everything inside this folder** (including `images/`).
4. Open the repository's **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then Save.
7. GitHub will give you a public `github.io` address.

You can later connect a custom domain if you buy one.

## Editing
Open `index.html` in a text editor. Search for the names/date/address if you need to change any details.
